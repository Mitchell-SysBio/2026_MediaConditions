# 2026_MediaConditions
**BMD Dataset Folder**
**Original MGC calculation scripts folder:**
This folder contains the scripts we used to calculate the Max Growth Concentration for each media condition. Example images are provided for use with the scripts. For Details on this method, see our publication in Bioinformatics Advances.
classifyFullPlates.m - loads images of 96-well plates and uses classifyPlatePhenotypes function to classify phenotype based on neural network output (bestNet.mat). 
DrugConcMetadata.xlsx - provides concentrations of each antibiotic in each well.
InputDialog.m - used by classifyPlatePhenotypes function to allow for manual corrections of well classifications.
makeDrugMaxConc.m - used with resulting well classifications to calculate the MaxDrugConc.

**Remaining files:**
BMDDatasetPrep.m - the script that performs basic preparation of max growth concentration data for use in future figures. 
BMDDatasetPrep.m - produces MGCFig1Variables.mat and STdPotFig1Variables.mat which are used for the development of figures. These are provided so that those later figures can be generated by user.
MGCRecordsFullBMDScreen.xlsx - used by BMDDatasetPrep to obtain Max Growth Conc values in all media and drug conditions. This excel document contains a record of all Max Growth Conc measurements.

**Dose Response Datasets Folder**
Files that contain growth curve data for dose response experiments shown in figure 4 and supplemental figure 2.
doseResponseVar1.mat - contains growth curve data for experiments in Fig 4B
doseResponseEAVar1.mat - contains growth curve data for experiments in Fig 4C
doseResponseEAVar2.mat - contains growth curve data for experiments in Fig 4D
doseResponseSupp2.mat - contains growth curve data for experiments in Supplemental Figure 2

**Genetic Screens Dataset Folder**
all_barcodes - folder that contains LFC data for each screen condition compared to no drug control as was output using DESeq2in R. S1 and S2 designations can be ignored; they were used to separate screens that were run in batch 1 or batch 2 of screens.
GeneticScreensDatasetPreparation.m - script that obtains LFC and p values from all_barcodes files and prepares them for further analysis.
GeneticScreensDataset.mat - output of script, saved to be used in Figure development screens.

**Figure 3:**
Fig3CorrAnalysis.m - calculate correlation coefficient and associated p values between normalized LFC from genetic screens and standardized potency from BMD screens. Saves output corrVariables.mat and .txt files to go into GSEA analysis.
GSEAWrapper_Fig3.m - use this and its function checkPWEnrichment.m to read .txt files and produce PW enrichment for all ontologies of interest. Produces gseaResults.mat. Uses pwAnnVar.mat to reference gene ontologies.
Fig3_postGSEA.m - use to evaluate results of GSEA and prepare input for REVIGO for GO BP output.
Then you must MANUALLY take forRevigo.xlsx inputs and run through REVIGO software and then save the output tables. Example REVIGO output provided with Revigo_PPoint01.xlsx.
With REVIGO outputs return to Fig3_postGSEA.m script to create pwFinVar.mat output with organized REVIGO results.
Fig3Panels.m - create figure panels

**Supplementary Information Files Generation Folder**
**Calculating growth rate subfolder:**
Results from separate experiments used to calculate growth rate in each media are in dated .xlsx files as summarized in gr_metadata.xslx and gr_conditions.
GRCalc.m - calculates growth rate using fit function and produces GRVar.mat which is saved for use in later functions.

**Supplemental Figure 1:**
SuppFig1A.m - relies on MGCFig1Variables.mat, StdPotFig1Variables.mat, and the output of the Calculating growth rate folder to plot growth rate vs standardized potency.
SuppFig1B.m - relies on excel sheet FolicAcidDrugScreenMGCs.xlsx that contains MGC measurements from the mini screen with folate synthesis targeting antibiotics.

**Supplemental Figure 2:**
SuppFig2.m - relies on doseResponseSupp2.mat found in Dose Response Dataset folder and calcDoseResponse.m in order to plot dose response curves for additional antibiotics.

**Supplementary Table 1:**
SuppTable1.m - relies on forTS1.mat to provide knockout gene names to be sorted by SMX or TMP specific sensitivity or resistance.

**Supplementary Table 2:**
SuppTable2.m - lies on gseaResults.mat to summarize key metrics of GSEA results using each gene ontology database.
